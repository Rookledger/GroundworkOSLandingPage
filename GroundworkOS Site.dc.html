Why it exists

Generic job software doesn't know what CIS is.

Groundwork runs on gangs, plant, retentions and deductions. Most tools ask you to bolt that on with spreadsheets and a bookkeeper.

GroundworkOS models it directly: subcontractor verification status, automatic CIS deduction on invoices, a monthly CIS300 return export, and expiry tracking for CSCS cards, NRSWA certifications and public liability insurance.

Every create, update and delete is recorded with full change history, so the audit trail is the system of record — not somebody's memory of the site.

Deployment

Two projects. One Cloudflare account.

GroundworkOS deploys as two Cloudflare projects — the frontend on Cloudflare Pages, the API as a Cloudflare Worker — wired together by a Workers Route so the frontend's relative API calls stay same-origin. Full setup is documented in DEPLOYMENT.md.

Frontend
React 19 + Vite
Tailwind v4, wouter routing
Backend
